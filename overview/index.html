    Overview

    Software that understands software.

    Sonde turns source, builds, dependencies, resources, database access patterns, accessibility, compliance posture, and agent work into one evidence mesh teams can query, verify, and improve.

    Why teams use Sonde

    Distinguished engineer pair for agents

    Sonde briefs agents before they edit, catches code smells while they work, and verifies the resulting delta after the change lands.

    SondeQL over the semantic mesh

    Ask ad hoc questions about architecture, dependencies, risk, resources, accessibility, and compliance without writing another one-off scanner.

    One engine everywhere

    Cockpit, CLI, SDK, MCP, linter, reports, CI workflows, LSP diagnostics, the VS Code extension, and API surfaces all consume the same evidence instead of forking logic.

    Probe-on-probe insight

    Probes can build on earlier probe results, turning small deterministic facts into stronger conclusions about the whole system.

    Auto-fix from every interface

    Sonde can fix thousands of lines in seconds from Cockpit, CLI, SDK, CI, or IDE flows, then rerun analysis to prove the structure actually improved.

    Optimized fix plans for agentic workflows

    Agent-generated changes can be converted into prioritized, dependency-aware fix plans that target the highest-value cleanup before review.

    Rich reports, not static summaries

    Share interactive, educational, collaborative, and actionable reports that keep every claim tied back to reproducible evidence.

    Holistic system understanding

    Sonde connects languages, build systems, package managers, logs, schema, data access, runtime resources, and dependency behavior into one model.

    Configurable by design

    Profiles, manifests, and custom probes let teams adapt Sonde to their codebase, standards, and workflows while still using the shared semantic mesh.

    Workflows Sonde improves

    AI-generated code cleanup

    When AI generates a large diff, Sonde findings can drive immediate cleanup so the final change is safer, clearer, and easier to review.

    AI safety and agent governance

    Racks for agents and MCP inspect tool boundaries, prompt and output contracts, recursive loops, approval surfaces, and unsafe parameterization.

    Compliance from code

    Map findings into accessibility, security, privacy, governance, VPAT, OSCAL, CSV, TSV, JSON, Markdown, PDF, and HTML evidence surfaces.

    Accessibility and localization verification

    Verify source-level accessibility, mobile parity, language coverage, translation quality, and UI contract rules before those failures reach users.

    Agent field notes (quoted directly from chat transcripts)

    Language breadth

    Sonde discovers language support from the same profiles the Cockpit uses so analysis, fix planning, and reporting can follow real polyglot systems instead of pretending one framework owns the whole codebase.
